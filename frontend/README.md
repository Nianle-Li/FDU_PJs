# Frontend

静态前端不需要构建步骤。启动后端后有两个入口：

```text
http://127.0.0.1:8000              # 用户端
http://127.0.0.1:8000/admin.html   # 管理员端
```

页面能力：

- 用户端：自然语言问答、浏览近期活动与预约/取消预约、查看我的行程、校园速览（建筑/设施/课程/活动）。
- 管理员端查询工作台：传统多条件检索与自然语言查询（展示 SQL 文本）。
- 管理员端数据浏览：历史查询、热门查询统计、热门活动、活动参与明细、数据表原始记录浏览。
- 管理员端数据维护：建筑、设施、活动的新增、修改、删除，以及 CSV 批量导入和查询记录写入。
