# PJ2 验收指引

> 测试文件统一放置于 `PJ2/NER/Chinese/test.txt` 和 `PJ2/NER/English/test.txt`。  
> 评分以 `PJ2/NER/check.py` 输出的 **micro avg F1** 为准。

## 统一环境安装

```bash
cd PJ2
pip install -r requirements.txt
```

---

## 任务一：HMM NER

**工作目录：`PJ2/Part1/src`**

```bash
cd PJ2/Part1
cd src
```

### 训练（合并 train + validation）

```bash
python train.py --language Chinese \
  --k_transition 0.1 --k_emission 0.5 \
  --unk_threshold 2 --unk_weight 0.75 \
  --include_validation

python train.py --language English \
  --k_transition 0.5 --k_emission 0.05 \
  --no_lowercase --unk_threshold 1 --unk_weight 1.0 \
  --include_validation
```

### 预测

```bash
python predict.py --language Chinese \
  --input ../../NER/Chinese/test.txt \
  --output ../outputs/chinese/test_pred.txt

python predict.py --language English \
  --input ../../NER/English/test.txt \
  --output ../outputs/english/test_pred.txt
```

### 评分

```bash
python -c "import sys; sys.path.insert(0,'../../NER'); from check import check; check('Chinese','../../NER/Chinese/test.txt','../outputs/chinese/test_pred.txt')"
python -c "import sys; sys.path.insert(0,'../../NER'); from check import check; check('English','../../NER/English/test.txt','../outputs/english/test_pred.txt')"
```

验证集参考：中文 F1 ≈ **0.9059**，英文 F1 ≈ **0.9484**

## 任务二：CRF NER

**工作目录：`PJ2/Part2`**

```bash
cd PJ2/Part2
```

任务二保留主方案与 Bonus 方案两套实现。其中 **Bonus 方案在验证集上结果更优**，建议作为默认验收方案；主方案可作为基础实现说明与对照方案。

### 推荐验收方案（Bonus）

#### 训练

```bash
python bonus/train_bonus.py --lang zh \
  --data_dir ../NER/Chinese --output_dir outputs/chinese_bonus \
  --template ../NER/template_for_crf.utf8

python bonus/train_bonus.py --lang en \
  --data_dir ../NER/English --output_dir outputs/english_bonus \
  --template ../NER/template_for_crf.utf8
```

#### 预测

```bash
python bonus/predict_bonus.py --lang zh --model_path outputs/chinese_bonus/model_bonus.crfsuite --test_path ../NER/Chinese/test.txt  --template ../NER/template_for_crf.utf8 --output_path outputs/chinese_bonus/test_pred.txt

python bonus/predict_bonus.py --lang en  --model_path outputs/english_bonus/model_bonus.crfsuite --test_path ../NER/English/test.txt --template ../NER/template_for_crf.utf8 --output_path outputs/english_bonus/test_pred.txt
```

#### 评分

```bash
python -c "
import sys; sys.path.insert(0, '../NER')
from check import check
check('Chinese', '../NER/Chinese/test.txt', 'outputs/chinese_bonus/test_pred.txt')
"
python -c "
import sys; sys.path.insert(0, '../NER')
from check import check
check('English', '../NER/English/test.txt', 'outputs/english_bonus/test_pred.txt')
"
```

验证集参考：中文 F1 ≈ **0.9530**，英文 F1 ≈ **0.9045**

### 训练（主方案）

```bash
python src/train.py --lang zh \
  --data_dir ../NER/Chinese --output_dir outputs/chinese

python src/train.py --lang en \
  --data_dir ../NER/English --output_dir outputs/english
```

### 预测（主方案）

```bash
python src/predict.py --lang zh --model_path outputs/chinese/model.pkl \
  --test_path ../NER/Chinese/test.txt --output_path outputs/chinese/test_pred.txt

python src/predict.py --lang en --model_path outputs/english/model.pkl \
  --test_path ../NER/English/test.txt --output_path outputs/english/test_pred.txt
```

### 评分

```bash
python -c "
import sys; sys.path.insert(0, '../NER')
from check import check
check('Chinese', '../NER/Chinese/test.txt', 'outputs/chinese/test_pred.txt')
"
python -c "
import sys; sys.path.insert(0, '../NER')
from check import check
check('English', '../NER/English/test.txt', 'outputs/english/test_pred.txt')
"
```

验证集参考：主方案中文 F1 ≈ **0.9523**、英文 F1 ≈ **0.9029**；Bonus 中文 F1 ≈ **0.9530**、英文 F1 ≈ **0.9045**
