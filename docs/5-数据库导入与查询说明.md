# 数据库导入与查询验收说明

本文档汇总数据库初始化、CSV 导入、基础查询验证和写入联调结果，用于课堂展示与项目验收。

## 一、初始化方式

### 1. Docker Compose 初始化

数据库使用 PostgreSQL 16，Docker Compose 配置见 `docker-compose.yml`。

```bash
docker compose up -d db
```

默认连接信息：

- 数据库：`fcqa`
- 用户：`postgres`
- 密码：`postgres`
- 本机端口：`5432`

首次创建数据卷时，Compose 会执行 `docker/postgres/01-init.sql`，进而调用 `db/init.sql`，完成建表、索引创建和初始 SQL 测试数据导入。

如需导入规模更大的 CSV 演示数据，可执行：

```bash
docker compose exec -w /opt/fcqa db psql -P pager=off -v ON_ERROR_STOP=1 -U postgres -d fcqa -f db/init_csv.sql
```

### 2. 本机 PostgreSQL 初始化

初始测试数据导入：

```bash
createdb fcqa
psql -P pager=off -v ON_ERROR_STOP=1 -d fcqa -f db/init.sql
psql -P pager=off -v ON_ERROR_STOP=1 -d fcqa -f db/verify_basic_queries.sql
```

CSV 演示数据导入：

```bash
createdb fcqa
psql -P pager=off -v ON_ERROR_STOP=1 -d fcqa -f db/init_csv.sql
psql -P pager=off -v ON_ERROR_STOP=1 -d fcqa -f db/verify_basic_queries.sql
```

`db/init_csv.sql` 会依次执行建表、CSV 导入和序列重置；`db/seeds/import_csv.sql` 会按外键依赖顺序导入 `db/seeds/csv/` 下的 14 份 CSV。

## 三、查询验收

`db/verify_basic_queries.sql` 可用于初始测试数据和 CSV 演示数据，覆盖以下典型查询：

- 按校区查询建筑。
- 按建筑查询设施。
- 按教师查询课程。
- 查询近期活动及其所在校区、建筑和设施。
- 统计每个校区各类建筑数量。
- 统计最常被查询的查询类别。
- 统计热门活动参与人数。
- 事务内写入并回滚，验证数据库写入能力。

如需一次性执行整份脚本：

```bash
docker compose exec db psql -P pager=off -v ON_ERROR_STOP=1 -U postgres -d fcqa -f /opt/fcqa/db/verify_basic_queries.sql
```

如需分步展示，可进入交互式 `psql`：

```bash
docker compose exec db psql -U postgres -d fcqa
```

## 四、写入联调验收

可使用事务内写入并回滚的方式展示基础存储能力，不污染演示数据：

```bash
docker compose exec db psql -P pager=off -v ON_ERROR_STOP=1 -U postgres -d fcqa -c "BEGIN; INSERT INTO users(user_id, name, department) VALUES (999999, '演示用户', '数据库测试') RETURNING user_id, name, department; SELECT count(*) AS user_count_in_tx FROM users; ROLLBACK;"
```

CSV 数据导入后，插入临时用户时应返回一条临时记录，并在事务内看到用户数临时增加为 51：

```text
user_id | name         | department
--------+--------------+--------------
999999  | 验收临时用户 | 数据库联调测试

user_count_inside_transaction
-----------------------------
51
```

随后执行 `ROLLBACK`，演示数据保持为 50 个用户。

## 五、索引与扩展检查

检查模糊检索扩展和索引是否已经创建：

```bash
docker compose exec db psql -P pager=off -v ON_ERROR_STOP=1 -U postgres -d fcqa -c "SELECT extname FROM pg_extension WHERE extname IN ('pg_trgm','unaccent') ORDER BY extname; SELECT count(*) AS fcqa_index_count FROM pg_indexes WHERE schemaname = 'public' AND indexname LIKE 'idx_%';"
```

已验证结果包含 `pg_trgm`、`unaccent`，并创建 27 个项目索引。
