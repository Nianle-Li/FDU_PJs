# 文档目录

本目录汇总项目最终提交所需的设计、实现、验收与演示文档。

- `0-需求分析说明书.md`：系统需求范围、业务规则和验收口径。
- `1-完整表结构说明.md`：数据库表结构、字段定义和表级约束说明。
- `2-关系模式说明.md`：关系模式、主键外键设计和建模依据。
- `3-规范性分析说明.md`：第一范式到 BCNF 的规范化分析。
- `4-主要约束设计说明.md`：数据库约束与索引策略说明。
- `5-数据库导入与查询说明.md`：数据库初始化、CSV 导入、查询验证和写入联调说明。
- `6-系统测试与验收说明.md`：自动化测试、数据库验证和人工验收检查说明。
- `7-系统功能介绍与演示说明.md`：系统功能全景介绍与课堂演示路径说明。
