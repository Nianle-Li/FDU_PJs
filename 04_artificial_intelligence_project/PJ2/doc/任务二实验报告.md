## 二、模型设计

### 2.1 线性链 CRF

对输入序列 $\mathbf{x} = (x_1, \ldots, x_n)$，线性链 CRF 对标注序列 $\mathbf{y}$ 建模：

$$P(\mathbf{y} \mid \mathbf{x}) = \frac{1}{Z(\mathbf{x})} \exp\!\left(\sum_{t=1}^{n} \sum_k \lambda_k f_k(y_{t-1}, y_t, \mathbf{x}, t)\right)$$

其中：
- $f_k(y_{t-1}, y_t, \mathbf{x}, t)$：特征函数，可依赖整个输入序列（CRF 相对于 HMM 的核心优势）
- $\lambda_k$：对应权重参数
- $Z(\mathbf{x})$：归一化因子，通过**前向算法**在 $O(n \cdot |Y|^2)$ 时间内计算

### 2.2 训练：最大对数似然 + L-BFGS

最大化正则化对数似然：

$$\mathcal{L}(\boldsymbol{\lambda}) = \sum_{i=1}^{N} \log P(\mathbf{y}^{(i)} \mid \mathbf{x}^{(i)}) - \frac{c_1 \|\boldsymbol{\lambda}\|_1 + c_2 \|\boldsymbol{\lambda}\|_2^2}{2}$$

梯度由**前向-后向算法**计算期望特征计数，使用 **L-BFGS** 拟牛顿法迭代优化，收敛速度远优于梯度下降。

### 2.3 解码：Viterbi 算法

推理时使用 Viterbi 算法，利用动态规划在 $O(n \cdot |Y|^2)$ 时间内求全局最优标注：

$$\delta_t(j) = \max_{i} \left[\delta_{t-1}(i) + \sum_k \lambda_k f_k(y_{t-1}=i, y_t=j, \mathbf{x}, t)\right]$$

$$y^* = \arg\max_{\mathbf{y}} P(\mathbf{y} \mid \mathbf{x})$$

### 2.4 CRF vs HMM

| 维度 | HMM | CRF |
|------|-----|-----|
| 建模方式 | 生成式 $P(\mathbf{x}, \mathbf{y})$ | 判别式 $P(\mathbf{y} \mid \mathbf{x})$ |
| 特征约束 | 独立性假设（当前词仅依赖当前状态）| 可使用任意上下文特征 |
| 性能 | 较低 | 显著更高 |
| 训练复杂度 | 低（EM/频率估计）| 较高（迭代优化）|

## 三、特征工程

### 3.1 中文特征（字符级，BMES 标注体系）

中文 NER 以单字为最小处理单元，特征围绕字符本身及其上下文构建：

| 特征组 | 具体特征 | 数量 |
|--------|----------|------|
| 当前字符 | `w[0]` | 1 |
| 上下文窗口 | `w[-2]`、`w[-1]`、`w[+1]`、`w[+2]` | 4 |
| 相邻 bigram | `w[-2]/w[-1]`、`w[-1]/w[0]`、`w[0]/w[+1]`、`w[+1]/w[+2]` | 4 |
| 三字 trigram | `w[-1]/w[0]/w[+1]` | 1 |
| 字符类型 | `is_chinese`、`is_digit`、`is_alpha`、`is_punctuation` | 4 |
| 句子边界 | `BOS`、`EOS` | ≤2 |

越界位置填充 `<BOS>` / `<EOS>` 占位符，避免边界错误。

### 3.2 英文特征（词级，BIO 标注体系）

英文 NER 以词为单元，实体边界与大写规律、词形模式高度相关：

| 特征组 | 具体特征 | 说明 |
|--------|----------|------|
| 词形 | `word.lower()`、`isupper()`、`istitle()`、`isdigit()` | 大写/标题格/纯数字 |
| 前后缀 | `prefix-1/2/3/4`、`suffix-1/2/3/4` | 形态学信息 |
| 词形模式 | `word_shape`（X/x/d 压缩）| 如 `John` → `Xx`，`IBM` → `X` |
| 上下文词 | `w[-2]/w[-1]/w[+1]/w[+2]`（小写）| 语境信息 |
| 上下文词形 | `w[-1].isupper()`、`w[+1].istitle()` 等 | 相邻词大写规律 |
| 相邻 bigram | `w[-1]/w[0]`、`w[0]/w[+1]` | 词序信息 |
| 句子边界 | `BOS`、`EOS` | 边界标记 |

### 4.2 Bonus 方案（pycrfsuite）

| 参数 | 值 |
|------|-----|
| `algorithm` | `lbfgs` |
| `c1` / `c2` | `0.05` / `0.05` |
| `max_iterations` | `200` |
| `feature.possible_transitions` | 由 B 模板检测动态决定（本模板文件含 10 条 B 模板，故为 `1`）|

## 六、对比分析

### 6.1 两种方案的特征差异

**初始模板方案**仅通过 10 条 Unigram 模板生成 col 0（token 本身）的窗口组合，无前缀/后缀等形态学特征。英文 NER 高度依赖词形线索（大写、前后缀），直接导致初始 Bonus 英文召回率低至 0.7278。

**改进后**，在模板特征基础上补充了两类额外特征（以 `%x[row,1]` 语义扩展）：
1. **词类型窗口特征**：col 1（UP/TI/DG/LC）在位置 [-2,+2] 的单项特征及 bigram/trigram 组合
2. **前后缀特征**：当前词及右邻词的 1~4 字符前缀/后缀

改进后英文 micro F1 从 0.8193 提升至 **0.9045**，召回率从 0.7278 恢复至 **0.8942**，与主方案基本持平甚至略优。

**中文结果接近**（0.9523 vs 0.9530）：中文 NER 的识别线索主要来自字符本身及上下文组合，模板方案已能完整捕获窗口内的 unigram/bigram，与主方案重叠度高，因此差距极小。

### 6.2 精确率 vs 召回率分析

改进前 Bonus 英文表现为**高精确率（0.937）、低召回率（0.728）**：模型倾向于"宁可漏标，不做错标"，说明特征表达不足时，CRF 对不确定位置偏向预测 `O`。这与 CRF 全局归一化机制一致——特征证据不充分时，模型降低实体类别置信度。

补充词类型和前后缀特征后，精确率从 0.9371 小幅降至 0.9151（更积极地识别实体），召回率大幅提升（+0.1664），整体 F1 提高 0.085。这验证了**特征工程是 CRF 性能上限的决定性因素**。

### 6.3 稀有标签问题

中文数据集中部分 S 型标签（`S-CONT`、`S-ORG`、`S-TITLE`、`S-RACE` 等）在验证集中 support=0，F1 报告为 0.0000，不影响 micro avg F1（micro avg 仅统计非零 support 的 token 级别准确性）。这是数据分布的正常现象。

### 6.4 最难识别的实体

英文中 `I-MISC`（0.8208）和中文中 `PRO`（0.8726）是最难识别的类别。前者因 MISC 类别边界模糊（含杂项如国籍/事件等），后者因专业名称在训练集中出现频率低、字符组合多样。

## 七、模型原理与实现说明

### 7.1 为什么用 CRF 而非独立分类器？

独立分类器（如 Logistic Regression）对每个位置独立预测，无法保证相邻标签的**全局一致性**（例如 `I-PER` 不能紧跟在 `B-ORG` 之后）。CRF 通过**转移特征** $f_k(y_{t-1}, y_t, \mathbf{x}, t)$ 对标签序列整体打分，Viterbi 解码保证输出的序列是全局最优且合法的。

### 7.2 前向算法与后向算法

**前向变量**（用于计算 $Z(\mathbf{x})$）：

$$\alpha_t(j) = \sum_i \alpha_{t-1}(i) \cdot \exp\!\left(\sum_k \lambda_k f_k(i, j, \mathbf{x}, t)\right), \quad \alpha_1(j) = \exp\!\left(\sum_k \lambda_k f_k(\text{start}, j, \mathbf{x}, 1)\right)$$

$$Z(\mathbf{x}) = \sum_j \alpha_n(j)$$

**后向变量**（用于计算边缘概率）：

$$\beta_t(i) = \sum_j \exp\!\left(\sum_k \lambda_k f_k(i, j, \mathbf{x}, t+1)\right) \cdot \beta_{t+1}(j), \quad \beta_n(i) = 1$$

**模型期望特征计数**（梯度所需）：

$$\mathbb{E}[f_k] = \sum_t \sum_{i,j} \frac{\alpha_t(i) \cdot \exp\!\left(\sum_k \lambda_k f_k(i,j,\mathbf{x},t+1)\right) \cdot \beta_{t+1}(j)}{Z(\mathbf{x})} \cdot f_k(i, j, \mathbf{x}, t+1)$$

### 7.3 梯度推导

参数 $\lambda_k$ 的梯度为**实际特征期望 − 模型期望**：

$$\frac{\partial \mathcal{L}}{\partial \lambda_k} = \sum_{i,t} f_k(y^{(i)}_{t-1}, y^{(i)}_t, \mathbf{x}^{(i)}, t) - \sum_{i,t} \mathbb{E}_{P(\mathbf{y}|\mathbf{x}^{(i)})}[f_k]$$

前一项是训练数据中 $f_k$ 出现的真实计数；后一项由前向-后向算法计算。

### 7.4 Viterbi 解码（含回溯）

Viterbi 算法利用动态规划求全局最优路径，分两阶段：

**前向（填表）**：维护 $\delta_t(j)$（到达位置 $t$ 且当前标签为 $j$ 的最大对数得分）和 $\psi_t(j)$（到达此状态的最优前驱标签）：

$$\delta_t(j) = \max_i \left[\delta_{t-1}(i) + \sum_k \lambda_k f_k(i, j, \mathbf{x}, t)\right], \quad \psi_t(j) = \arg\max_i[\cdots]$$

**回溯（恢复路径）**：

$$y^*_n = \arg\max_j \delta_n(j), \quad y^*_t = \psi_{t+1}(y^*_{t+1}), \quad t = n-1, \ldots, 1$$

时间复杂度 $O(n \cdot |Y|^2)$，保证输出序列全局最优。

### 7.5 Bonus 模板语义与转移特征处理

#### 7.5.1 模板语法

`template_for_crf.utf8` 中每条模板由**前缀 + 名称 + 模板串**组成：

```
U06:%x[-1,0]/%x[0,0]
B02:%x[0,0]
```

`%x[row, col]` 表示**当前处理位置偏移 `row` 行、第 `col` 列的输入值**。`col=0` 对应 token 列，`col=1` 对应辅助特征列（本实现中为字符/词类型标记）。

#### 7.5.2 U 模板（状态特征）

`U` 前缀模板生成**状态特征（emission feature）**，即与当前标签 $y_t$ 绑定的特征，形如：

$$f_k(y_t, \mathbf{x}, t) = \mathbf{1}[y_t = s] \cdot \mathbf{1}[\text{template}(t) = v]$$

`features_template.py` 中 `_expand_template` 函数显式将每条 `U` 模板展开为字符串，作为 pycrfsuite 的离散特征传入，框架会自动为每个 `(状态, 特征值)` 对学习权重 $\lambda_k$。

#### 7.5.3 B 模板与转移特征的关系

CRF++ 中 `B` 前缀模板用于生成**转移特征（transition feature）**，形如：

$$f_k(y_{t-1}, y_t, \mathbf{x}, t) = \mathbf{1}[y_{t-1} = s'] \cdot \mathbf{1}[y_t = s] \cdot \mathbf{1}[\text{template}(t) = v]$$

即同一条模板值，但同时与**前驱标签和当前标签的组合**绑定。在 CRF++ 中若不写 `B` 模板，模型就只有纯状态特征，无法利用标签间的转移约束。

**本实现的处理方式**：pycrfsuite 与 CRF++ 的特征协议不同——pycrfsuite 将状态特征和转移参数分开处理，转移矩阵 $T[y_{t-1}, y_t]$ 由框架在训练阶段通过最大似然自动学习，无法在 Python 侧将 `B` 模板手工展开为特征字符串。实现路径如下：

1. `parse_template()` 同时解析 U/B 两类模板，返回 `(unigram_templates, bigram_templates)` 两个列表
2. `extract_features_from_template()` 仅展开 `unigram_templates` 为状态特征字符串，传入 `trainer.append(xseq, yseq)`
3. `train_bonus.py` 检测 `len(bigram_templates) > 0`，自动激活 `feature.possible_transitions=1`——与 CRF++ `B` 模板为每个 $(y_{t-1}, y_t)$ 对分配转移权重的效果等价
4. 非法转移（如 `B-PER → I-ORG`）在训练中因证据不足获得负权重，解码时被 Viterbi 自动压制

#### 7.5.4 与 CRF++ 标准工作流的对应关系

给定模板文件 `template_for_crf.utf8` 后，CRF++ 的标准工作流是直接读取多列输入和模板文件，并在工具内部完成特征展开。本实现将该过程显式拆分为 Python 层的 `parse_template` 与 `_expand_template` 两步，再调用 pycrfsuite 完成训练与解码。二者在特征语义上保持一致，差异仅在于模板展开的位置不同：前者由工具内部实现，后者由脚本侧显式完成，因此更便于检查模板解析结果、扩展辅助列特征，并解释 Bonus 部分中模板到模型参数的映射关系。

## 八、总结

本实验围绕线性链 CRF 在中英文命名实体识别任务中的应用展开，完整实现了数据读取、特征构建、模型训练、验证评估与测试集推理流程。主方案基于 `sklearn-crfsuite` 与人工特征工程，英文验证集 micro F1 达到 **0.9029**，中文达到 **0.9523**，说明所设计的上下文窗口、词形模式和边界特征能够较好支撑序列标注任务。

在 Bonus 部分，报告进一步基于给定 `template_for_crf.utf8` 模板，实现了 `pycrfsuite` 下的模板驱动 CRF 方案，并对 U 模板与 B 模板在状态特征、转移特征中的作用进行了对应说明。改进后的 Bonus 英文与中文验证集 micro F1 分别达到 **0.9045** 和 **0.9530**，均不低于主方案结果，表明在模板语义得到正确实现并补充必要辅助特征后，模板驱动方案具备与手工特征方案相当的竞争力。

综合实验结果可以得出两点结论。其一，CRF 在中英文 NER 上仍然具有稳定有效的性能表现，但其上限高度依赖特征工程质量；其二，模板驱动方案并非天然弱于手工特征方案，关键在于是否为不同语言补足必要的形态学与上下文信号。基于当前结果，任务二在验收时可优先展示 Bonus 方案，主方案作为基础实现和对照方案保留。
